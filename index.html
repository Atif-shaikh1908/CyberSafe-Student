About CyberSafe Student

CyberSafe Student is a field project focused on cybersecurity awareness among college students. The project studies basic online safety practices through a structured survey and provides educational cybersecurity content through this website.

Cybersecurity Topics

🔐 Password Safety

Learn about strong passwords, password reuse, account protection and safer login practices.

🎣 Phishing Awareness

Understand suspicious messages, links and common warning signs of phishing.

🌐 Safe Browsing

Learn how to check website addresses and make safer decisions while browsing online.

📱 Mobile Security

Learn about screen locks, updates, app permissions and trusted applications.

🔒 Privacy Awareness

Understand how to handle and share personal information more carefully online.

Project Process
