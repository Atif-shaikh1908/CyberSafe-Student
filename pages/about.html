About the Project

CyberSafe Student is a field project focused on understanding basic cybersecurity awareness among college students.

The project uses a structured student survey to study common practices related to passwords, phishing, safe browsing, mobile security and privacy.

Based on the study, this website provides simple educational information that can help students understand common cybersecurity risks and safer online practices.

Project Details

🎓 Academic Area

B.Sc. Computer Science — Community Engagement / Field Project.

🔎 Study Focus

Cybersecurity awareness and online safety practices among college students.

📝 Data Collection

A structured questionnaire is used to collect primary survey responses.

💻 Website Technology

HTML, CSS and JavaScript are used to create the educational website.

📊 Data Analysis

Survey responses are organized and analyzed using frequencies, percentages, tables and charts.

🎯 Project Purpose

To identify cybersecurity awareness patterns and provide practical educational information for students.

Topics Covered

01

Password Safety

Strong passwords, password reuse and account protection.

02

Phishing Awareness

Recognizing suspicious messages, links and information requests.

03

Safe Browsing

Checking websites and making careful decisions while browsing online.

04

Mobile Security

Device locks, application permissions, updates and mobile safety.

05

Privacy Awareness

Responsible sharing of personal information and privacy settings.

06

Survey Analysis

Presenting and interpreting the collected cybersecurity awareness data.

Project Process

01

Field Study

Identify the cybersecurity awareness problem through student interaction and observation.

02

Survey

Collect primary data using the structured questionnaire.

03

Analysis

Organize and analyze the collected survey responses.

04

Website

Present cybersecurity awareness information through the educational website.

Academic Purpose

The project combines field study, primary data collection, data analysis and practical website development.

It demonstrates how Computer Science skills can be applied to identify a real-world awareness problem and develop a digital educational resource around it.
