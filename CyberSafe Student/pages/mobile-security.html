Keep your mobile device secure

Smartphones are commonly used for communication, education, entertainment, banking and online services. Good security practices can help protect your device and information.

Mobile Security Practices

🔒 Use a Screen Lock

Use an appropriate screen lock to help prevent unauthorized access to your device.

📲 Review App Permissions

Check which permissions applications request and review them when necessary.

🔄 Keep Apps Updated

Install updates for your operating system and applications when they are available.

📥 Use Trusted Sources

Download applications from trusted and appropriate sources whenever possible.

☁️ Protect Important Data

Keep important information backed up using suitable and trusted storage methods.

👀 Be Careful With Personal Information

Think carefully before sharing personal information through mobile applications and online services.
